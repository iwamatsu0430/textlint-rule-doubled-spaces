# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report them privately through GitHub instead:
[Report a vulnerability](https://github.com/iwamatsu0430/textlint-rule-doubled-spaces/security/advisories/new)
(the **Security** tab → **Report a vulnerability**).

Include what you found, how to reproduce it, and which version or commit you used.
Reports are welcome in English or Japanese.

## Supported versions

Only the latest version published on npm gets security fixes.
